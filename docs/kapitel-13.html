Eine Exception in einer Schleife abfangen

Hier setzt du zwei bekannte Bausteine neu zusammen: try und catch stehen im Block einer Schleife. Das Beispiel benutzt die Methode fee aus Kapitel 11. Sie berechnet die Parkgebühr und wirft eine Exception, wenn die Parkdauer kleiner als 1 Stunde ist. Diesmal rechnet das Programm für drei Autos auf dem Festivalparkplatz nacheinander die Gebühr aus. Das zweite Auto hat eine ungültige Parkdauer von 0 Stunden.

Klick dich zuerst durch die Fassung mit try im Block der Schleife. Stell dann die Fassung mit try um die ganze Schleife ein. Achte darauf, was nach der Exception mit dem dritten Auto passiert.

Steht try im Block der Schleife, fängt catch die Exception für genau dieses eine Auto ab. Danach holt die Schleife den nächsten Wert, und das dritte Auto bekommt seine Gebühr. Steht try um die ganze Schleife, bricht Java bei der Exception die ganze Schleife ab. Das dritte Auto prüft das Programm dann gar nicht mehr.

Fünf Regeln zum Merken

  1. Ein Attribut mit static gibt es nur einmal. Es gehört der Klasse, und alle Objekte teilen es sich. Ändert eine Methode es, gilt der neue Wert für alle Objekte.
  2. Eine Methode mit static rufst du über den Klassennamen auf, zum Beispiel Wristband.nextDay(). Eine Methode ohne static rufst du an einem Objekt auf, zum Beispiel lena.isValid().
  3. Zuerst prüfen, dann rechnen: Ist ein Wert ungültig, wirfst du die Exception am Anfang der Methode, bevor sich etwas ändert.
  4. Soll eine Schleife nach einer Exception weiterlaufen, stehen try und catch im Block der Schleife.
  5. Steht ein return im Block einer Schleife, endet mit ihm die ganze Methode und damit auch die Schleife.

Vier Fehler beim Zusammensetzen

Diese Fehler passieren oft, wenn mehrere Bausteine zusammenkommen. Die ersten beiden unterstreicht VS Code rot. Der dritte erzeugt eine gelbe Warnung. Den vierten findet erst der Test.
