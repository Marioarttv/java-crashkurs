Stell dir einen Kaffeeautomaten vor. Er hat genau drei Knöpfe: klein, mittel und groß. Einen vierten Knopf gibt es nicht. Du kannst auch nichts selbst eintippen. Du wählst immer eine der drei Größen, und der Automat weiß für jede Größe, was er tun muss.

Dieses Kapitel zeigt zwei Dinge, die genau dazu passen. Ein Enum legt fest, welche Werte erlaubt sind. Ein switch wählt je nach Wert den passenden Programmteil aus.

Ein Enum: eine feste Liste erlaubter Werte

Ein Enum ist ein Typ mit einer festen Liste erlaubter Werte. Es steht wie eine Klasse in einer eigenen Datei. Statt class steht dort das Wort enum. Die Datei für die drei Bechergrößen heißt Size.java:

Es gibt einen Typ mit fester Liste namens Size. Seine erlaubten Werte sind SMALL, MEDIUM und LARGE.

Die Werte schreibst du in Großbuchstaben und trennst sie mit Kommas. Mehr steht in so einer Datei oft nicht.

Jetzt kannst du Size als Typ für eine Variable benutzen, genau wie int oder String. Vor den Wert schreibst du immer den Namen des Enums und einen Punkt:

Leg eine Variable vom Typ Size mit dem Namen size an und speichere darin den Wert MEDIUM aus der Liste Size.

Warum kein Text?

Du könntest die Größe auch als Text speichern, zum Beispiel String size = "MEDUIM";. Siehst du den Tippfehler? Java sieht ihn nicht. Jeder Text ist erlaubt, also läuft das Programm und rechnet mit einer Größe, die es nicht gibt.

Beim Enum passiert das nicht. Schreibst du Size.MEDUIM, unterstreicht VS Code die Stelle sofort rot und meldet MEDUIM cannot be resolved or is not a field. Das heißt: In der Liste Size gibt es keinen Wert mit diesem Namen. So fällt der Tippfehler auf, bevor das Programm startet.

Dasselbe mit switch

Mit switch fragst du nur einmal nach dem Wert einer Variable. Danach springt Java direkt zum passenden Fall. Ein switch hat vier Bauteile:

switchDas Wort „wähle aus“Damit fängt die Auswahl an.
(size)Die VariableNach ihrem Wert wählt Java aus. Sie steht in runden Klammern.
case SMALL:Ein FallHinter case steht ein möglicher Wert, danach ein Doppelpunkt. Den Namen des Enums brauchst du hier nicht.
break;Das Ende des FallsDamit springt Java aus dem switch heraus.

Alles zusammen steht in einem Block, also zwischen geschweiften Klammern. Lies den Anfang so:

Schau nach, welchen Wert size hat. Im Fall SMALL: speichere 200 in ml und hör dann auf.

Java prüft hier keine Bedingungen nacheinander. Es schaut einmal auf den Wert von size und springt direkt zum passenden case. Die Fälle darüber und darunter laufen nicht.

Achte auf Zeile 2: ml bekommt schon vor dem switch einen Startwert. Der passende Fall überschreibt ihn. Nach dem switch benutzt du die Variable weiter. Dieses Muster brauchst du noch öfter.

Was passiert ohne break?

Das break am Ende jedes Falls sieht unwichtig aus. Unten steht derselbe Code wie eben, nur ohne break. Wähl nacheinander alle drei Größen und schau, welchen Wert ml am Ende hat.

Ein case ist nur eine Einsprungstelle, keine Bedingung. Java springt beim passenden Fall hinein. Danach läuft es Zeile für Zeile weiter nach unten, bis ein break kommt oder der switch endet. Jeder spätere Fall überschreibt dann den Wert von ml. Darum gehört ans Ende jedes Falls ein break, auch hinter den letzten. Dort ändert es nichts, aber so vergisst du es nie.

default: alle anderen Fälle

Manchmal sind nicht alle Fälle verschieden. Nur der große Becher bekommt zwei Portionen Kaffee, alle anderen eine. Dafür gibt es default. Das heißt „in allen anderen Fällen“ und ist wie das else am Ende einer if-Kette.

Schau nach, welchen Wert size hat. Im Fall LARGE speichere 2 in shots. In allen anderen Fällen speichere 1.

default steht meistens am Ende. Dort brauchst du kein break mehr, denn der switch endet direkt danach.

switch in einer Methode: einen Wert zurückgeben

Bisher stand der switch mitten in einem Programm. In den Aufgaben steht er in einer Methode, und die Methode gibt das Ergebnis mit return zurück (Kapitel 3).

Eine Methode mit switch baust du in drei Schritten:

  1. Leg vor dem switch eine Variable mit Startwert an: int ml = 0; Für Text nimmst du einen leeren Text, also zwei Anführungszeichen ohne Zeichen dazwischen: String text = "";
  2. Setz im switch für jeden Fall den neuen Wert und schließ den Fall mit break; ab.
  3. Gib nach dem switch das Ergebnis mit return zurück.

Eine andere Schreibweise. Manchmal siehst du einen switch mit Pfeilen statt Doppelpunkten:

Mit Pfeilen brauchst du kein break. Du darfst beide Schreibweisen aber nicht in einem switch mischen. So kannst du Pfeile lesen, wenn sie dir begegnen. Schreib in diesem Kurs die Fassung mit Doppelpunkt und break.

Sechs Regeln zum Merken

  1. Ein Enum ist ein Typ mit einer festen Liste erlaubter Werte, zum Beispiel public enum Size { SMALL, MEDIUM, LARGE }.
  2. Einen Wert schreibst du mit dem Namen des Enums davor: Size.LARGE. Zwei Werte vergleichst du mit ==.
  3. switch (variable) schaut einmal auf den Wert und springt zum passenden case. Hinter case steht der Wert ohne Enum-Namen: case LARGE:
  4. Jeder Fall endet mit break;, auch der letzte. Ohne break laufen auch die Fälle darunter.
  5. default: heißt „in allen anderen Fällen“, wie else.
  6. Muster: Leg vor dem switch eine Variable mit Startwert an (0 für Zahlen, "" für Text). Setz ihren Wert in jedem Fall und benutz ihn nach dem switch.
