Leg eine Variable für eine ganze Zahl (int) mit dem Namen students an und speichere darin den Wert 24.

Wie jede Anweisung endet auch diese mit einem Semikolon. Einen Wert mit = in einer Variable speichern heißt Zuweisung. Lies = immer als „speichere“, nie als „ist gleich“.

Vier Typen, die du brauchst

Der Typ legt fest, welche Art von Wert in die Variable passt. Für den Anfang reichen vier:

Am häufigsten brauchst du int. boolean wird ab Kapitel 7 wichtig, wenn Programme entscheiden.

Wie Namen aussehen

Namen von Variablen beginnen mit einem kleinen Buchstaben und haben keine Leerzeichen. Besteht ein Name aus mehreren Wörtern, beginnt jedes weitere Wort mit einem Großbuchstaben: pricePerPerson. Java unterscheidet Groß- und Kleinschreibung. pricePerPerson und priceperperson sind zwei verschiedene Namen.

Eine Variable benutzen und ändern

Willst du den Wert einer Variable ausgeben, schreibst du ihren Namen ohne Anführungszeichen in die Klammern: System.out.println(students); gibt 24 aus. Mit Anführungszeichen wäre es Text: System.out.println("students"); gibt das Wort students aus.

Den Wert einer Variable kannst du später ändern. Dann steht kein Typ mehr davor, denn die Variable gibt es schon. Im Beispiel meldet sich eine Person nach. Klick dich durch und stell danach andere Werte ein.

Zeile 3 sieht als Gleichung unsinnig aus, denn keine Zahl ist gleich sich selbst plus 1. Als Anweisung ergibt sie Sinn: Java rechnet zuerst die rechte Seite mit dem aktuellen Wert aus. Erst danach speichert es das Ergebnis links. Der alte Wert ist dann weg.

Rechnen

Java rechnet mit + (plus), - (minus), * (mal) und / (geteilt). Es gilt Punkt vor Strich: 2 + 3 * 4 ist 14. Brauchst du eine andere Reihenfolge, setzt du runde Klammern: (2 + 3) * 4 ist 20.

Statt mit Zahlen rechnest du meistens mit Variablen. Java setzt dann den Wert ein, der gerade in der Variable steht. Das Ergebnis speicherst du in einer neuen Variable:

Text und Zahl verbinden

Bei der Ausgabe willst du oft einen Text und eine Zahl in einer Zeile. Dafür verbindest du beide mit +. Steht links von + ein Text, rechnet Java nicht, sondern hängt die Zahl hinten an den Text an. Teilen: Ganze Zahlen schneiden ab

Beim Teilen gibt es eine Überraschung. Teilst du zwei ganze Zahlen, ist das Ergebnis wieder eine ganze Zahl. Java schneidet alles nach dem Komma ab. Es rundet nicht. 7 / 2 ist also 3, nicht 3,5.

Für die Fahrt heißt das: In jedes Zimmer passen vier Personen. Wie viele Zimmer werden voll, und wie viele Personen bleiben übrig? Für den Rest hat Java das Zeichen %. 26 % 4 ist 2, denn 26 geteilt durch 4 ist 6, Rest 2. Probier 24, 26 und 27 Personen aus.

Bei 27 Personen ist 27 geteilt durch 4 genau gerechnet 6,75. Java macht daraus 6. Willst du ein Ergebnis mit Komma, muss eine der Zahlen eine Kommazahl sein: 7.0 / 2 ist 3.5. Java schreibt Kommazahlen immer mit Punkt.

Genau so, wie es in der Aufgabe steht

In der Präsenzübung prüfen Tests deinen Code. Manche lesen sogar deinen Quelltext, also den geschriebenen Code, und suchen nach dem verlangten Namen und Wert. Ein Buchstabe anders, und der Test ist rot. Drei Dinge helfen dir dabei.

Die Wörter in der Aufgabe. Aufgaben sind oft so formuliert: „Deklariere eine lokale Variable vom Typ int mit dem Namen seats und initialisiere sie mit dem Wert 50.“ Das heißt:

  • deklarieren: die Variable anlegen, also Typ und Name hinschreiben,
  • initialisieren: den ersten Wert in ihr speichern,
  • lokal: Die Variable steht in einem Block, zum Beispiel im Block von main.

Meistens machst du beides in einer Zeile. Aus dem Satz wird also diese eine Zeile:

Getrennt geht es auch: int seats; deklariert die Variable, und erst später speichert seats = 50; den ersten Wert. Bis dahin hat die Variable keinen Wert, und du darfst sie noch nicht benutzen.

Die Namen. Schreib den Namen genau so ab, wie er in der Aufgabe steht, mit jedem Groß- und Kleinbuchstaben.

Die Zahlen. Im deutschen Text steht oft ein Tausenderpunkt: „1.800 Euro“. In Java schreibst du 1800, ohne Punkt. Der Punkt ist in Java das Komma einer Kommazahl. 1.800 wäre für Java die Zahl 1,8.

Sechs Regeln zum Merken

  1. Eine Variable anlegen: Typ, Name, =, Wert, Semikolon. Beispiel: int students = 24;
  2. = heißt „speichere“: Java rechnet zuerst rechts aus und speichert das Ergebnis in der Variable links. Der alte Wert ist danach weg.
  3. Jede Variable legst du nur einmal mit Typ an. Zum Ändern schreibst du sie ohne Typ: students = students + 1; oder kurz students++;
  4. int ganze Zahl, double Kommazahl mit Punkt, String Text in Anführungszeichen, boolean true oder false.
  5. Punkt vor Strich. Teilst du zwei ganze Zahlen, schneidet Java nach dem Komma ab: 7 / 2 ist 3. % gibt den Rest.
  6. "Text: " + zahl hängt die Zahl an den Text. Zahlen ohne Tausenderpunkt: 1800, nicht 1.800. Namen genau wie in der Aufgabe.
