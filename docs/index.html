Java-Crashkurs

Von null bis zur Präsenzübung: Java Schritt für Schritt, mit Beispielen zum Durchklicken und Aufgaben zum Selbstschreiben. Du brauchst kein Vorwissen.

Für wen und wozu

Dieser Kurs ist für dich, wenn du Java lernen willst und in den Grundlagen noch unsicher bist. Vielleicht hast du bisher wenig selbst getippt. Vielleicht kennst du einige Begriffe, kannst aber noch kein Programm allein schreiben. Beides ist ein guter Ausgangspunkt.

In der Präsenzübung arbeitest du allein in VS Code, ohne Hilfe. Dafür musst du jeden Schritt selbst können: eine Klasse anlegen, Variablen und Methoden schreiben, Objekte erzeugen und benutzen. Du steuerst den Ablauf mit if, switch und Schleifen und liest Fehlermeldungen. Genau das übst du hier, ab Kapitel 1.

Die Kapitel

Die Kapitel bauen aufeinander auf. Fang mit Kapitel 1 an, auch wenn dir die ersten Schritte bekannt vorkommen. Unter jedem Kapitel siehst du, wie viele Aufgaben du geschafft hast. Das merkt sich dein Browser.

Mit dem ersten Kapitel anfangen

So arbeitest du

Jedes Kapitel hat dieselben drei Teile:

  • LesenEin Beispiel aus dem Alltag, dann dasselbe in Java. Farben zeigen, welche Teile zusammengehören.
  • DurchklickenProgramme laufen Schritt für Schritt. Du siehst, welche Zeile gerade läuft und was im Speicher steht. Dazu kurze Fragen.
  • Selbst schreibenDrei Aufgaben im Übungsprojekt in VS Code. Ein Test sagt dir, ob deine Lösung stimmt.

Für ein Kapitel brauchst du etwa 20 bis 40 Minuten. Arbeite die Kapitel der Reihe nach durch, denn sie bauen aufeinander auf. Lass die Aufgaben nicht aus. Vom Lesen allein lernst du das Programmieren nicht. Erst beim eigenen Tippen merkst du, was schon sitzt.

Jedes Kapitel hat einen Kasten „Regeln zum Merken“. Übertrag diese Regeln in deine eigenen Notizen. In der Präsenzübung darfst du nur die Vorlesungsfolien mit deinen eigenen Notizen benutzen, nicht diese Seite.

Das Übungsprojekt holen

Die Aufgaben schreibst du in einem eigenen Projekt in VS Code. Dafür brauchst du VS Code mit der Erweiterung „Extension Pack for Java“ und Java 21, genau wie für die Übungen. Das Projekt liegt auf GitHub unter dieser Adresse:

https://github.com/Marioarttv/java-crashkurs

  1. Öffne VS Code. Drück F1. Oben erscheint ein Eingabefeld.
  2. Tippe Git: Clone und wähl den Befehl mit Enter aus.
  3. Füg die Adresse von oben ein und drück Enter.
  4. Wähl einen Ordner, in dem das Projekt liegen soll, zum Beispiel deine Dokumente. Klick auf „Select as Repository Destination“. VS Code lädt das Projekt herunter.
  5. Unten rechts fragt VS Code, ob es das Projekt öffnen soll. Klick auf „Open“.
  6. Fragt VS Code, ob du den Autoren der Dateien vertraust, klick auf „Yes, I trust the authors“. Sonst startet Java nicht.
  7. Warte, bis unten in der Statusleiste nichts mehr lädt. Beim ersten Öffnen richtet VS Code Java und Gradle ein, das Werkzeug für die Tests. Das kann ein paar Minuten dauern.

Den ersten Test starten

Ein Test ist ein Prüfprogramm, das deinen Code mit Beispielen startet und das Ergebnis mit der Vorgabe vergleicht. So prüfst du, ob alles eingerichtet ist:

  1. Klick links oben auf das Symbol mit den zwei Blättern. Das ist der Explorer.
  2. Öffne src/test/java/de/phl/crashkurs/k01/MensaBoardTest.java.
  3. Klick links neben der Zeile class MensaBoardTest auf den kleinen grünen Pfeil.
  4. Nach ein paar Sekunden erscheint ein rotes Kreuz mit einer deutschen Meldung. Genau so soll es sein: Alles funktioniert, die Aufgabe ist nur noch nicht gelöst.

Den Test kannst du auch im Terminal starten, dem Textfenster für Befehle. Öffne es über das Menü „Terminal“, „New Terminal“, und tippe:

./gradlew test --tests "*k01.MensaBoardTest"

Unter Windows schreibst du .\gradlew.bat statt ./gradlew. Die Aufgaben liegen in src/main/java/de/phl/crashkurs, in einem Ordner je Kapitel: k01 gehört zu Kapitel 1, k02 zu Kapitel 2 und so weiter.

Wenn Java auf deinem Rechner nicht läuft

Startet kein Test, oder zeigt VS Code Fehler beim Einrichten von Java, dann nimm Codespaces. Das ist VS Code im Browser, mit fertig eingerichtetem Java. Du brauchst nur ein GitHub-Konto.

  1. Öffne die Adresse des Projekts im Browser und melde dich bei GitHub an.
  2. Klick auf den grünen Knopf „Code“, dann auf den Reiter „Codespaces“ und auf „Create codespace on main“.
  3. Warte, bis sich VS Code im Browser öffnet und unten nichts mehr lädt. Danach arbeitest du genauso wie auf dem eigenen Rechner.

GitHub gibt jedem Konto pro Monat eine begrenzte Zahl kostenloser Stunden für Codespaces. Schließ den Browser-Tab, wenn du fertig bist. Deinen Codespace findest du später unter „Code“, „Codespaces“ wieder.
