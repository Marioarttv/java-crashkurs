Das solltest du schon kennen: Variablen (benannte Speicherplätze für Werte) aus Kapitel 2, System.out.println (Text ausgeben) aus Kapitel 1, Methoden mit return aus Kapitel 3, Attribute (Variablen, die zu einem Objekt gehören) aus Kapitel 4 und static aus Kapitel 6.

Im Alltag entscheidest du ständig so: Wenn es regnet, nehme ich den Schirm mit. Regnet es nicht, lässt du ihn zu Hause. Genau das kann ein Programm auch. Es prüft eine Frage mit der Antwort Ja oder Nein. Nur bei Ja führt es die zugehörigen Anweisungen aus.

In Java heißt „wenn“ if. So eine Entscheidung besteht immer aus drei Teilen:

ifDas Wort „wenn“Damit fängt jede Entscheidung an.
(points >= 50)Die BedingungEine Frage in runden Klammern. Die Antwort ist immer Ja oder Nein. Java sagt dazu wahr und falsch.
{ ... }Der BlockAlles zwischen den geschweiften Klammern. Dieser Teil läuft nur, wenn die Bedingung wahr ist (Antwort Ja).

Lies dir so eine Zeile am besten laut als deutschen Satz vor:

Wenn points mindestens 50 ist, dann mach das, was im Block steht.

Die Farben bleiben auf der ganzen Seite gleich: violett für if und else, orange für die Bedingung, blau für den Block.

Ein if allein: einen Block ausführen oder überspringen

Ein Programm läuft Zeile für Zeile von oben nach unten. Das Beispiel unten prüft eine Punktzahl. Klick auf „Nächster Schritt“ und schau auf die gelb markierte Zeile. Das ist die Zeile, die Java gerade ausführt.

Stell danach im Kasten 49 Punkte ein und klick dich noch einmal durch. Schau dabei auf Zeile 3: Was passiert mit ihr?

Ist die Bedingung falsch (Antwort Nein), überspringt Java den ganzen Block. Die Zeile nach der schließenden geschweiften Klammer läuft in jedem Fall.

Werte in einer Bedingung vergleichen

In einer Bedingung vergleichst du meistens zwei Werte. Dafür gibt es sechs Vergleichszeichen:

>größer als<kleiner als
>=größer oder gleich („mindestens“)<=kleiner oder gleich („höchstens“)
==gleich!=ungleich

Viele Fehler passieren genau an der Grenze: Zählt die 50 noch mit oder nicht? Probier es unten aus, bevor du weiterliest. Klick bei 50 und 50 einmal auf > und einmal auf >=.

Wichtig bei „gleich“: Zum Vergleichen brauchst du zwei Gleichheitszeichen, also ==. Ein einzelnes = ist eine Zuweisung. Es speichert einen Wert in einer Variable, wie in int points = 62;.

Entweder oder: if und else

Oft soll in beiden Fällen etwas passieren: ein Block für wahr (Ja), ein anderer für falsch (Nein). Dafür hängst du else an. Das heißt „sonst“ und bekommt einen eigenen Block.

Wenn points mindestens 50 ist, gib „bestanden“ aus. Sonst gib „nicht bestanden“ aus.

Von diesen beiden Blöcken läuft immer genau einer. Nie beide, nie keiner.

Drei Fälle unterscheiden: if, else if und else

Manchmal reichen zwei Fälle nicht. Dann baust du eine Kette mit else if („sonst, wenn“) für eine zweite Bedingung. Java prüft die Bedingungen von oben nach unten. Sobald eine Bedingung wahr ist (Antwort Ja), läuft genau dieser Block. Alle weiteren Bedingungen darunter prüft Java gar nicht mehr. War keine Bedingung wahr, läuft der else-Block.

Ein Beispiel zur Klausur: Ab 85 Punkten gibt es „sehr gut“, ab 50 Punkten „bestanden“, darunter „nicht bestanden“. Probier im Kasten 90, 60 und 30 Punkte aus. Achte bei 90 darauf: 90 ist auch mindestens 50. Trotzdem läuft nur der erste passende Block.

Zwei Bedingungen verbinden: und, oder, nicht

Manchmal hängt eine Entscheidung von zwei Fragen ab: Wenn es warm ist und ich mindestens zwei Stunden Zeit habe, gehe ich ins Freibad. Ist eine der beiden Antworten Nein, bleibst du zu Hause.

Dafür verbindest du zwei Bedingungen zu einer. Java hat drei Zeichen dafür:

&&undNur wahr, wenn beide Bedingungen wahr sind.
||oderWahr, wenn mindestens eine der beiden wahr ist.
!nichtDreht das Ergebnis um: Aus wahr wird falsch, aus falsch wird wahr.

Die ganze Verbindung steht in den runden Klammern hinter if. Sie ist eine einzige Bedingung mit der Antwort wahr oder falsch. Probier die drei Fälle im Kasten aus.

Für || tippst du zweimal einen senkrechten Strich. Auf einer deutschen Tastatur bekommst du ihn am Mac mit Alt + 7, unter Windows mit Alt Gr + <. Das Zeichen ! steht direkt vor dem, was es umdreht. !(points >= 50) heißt also „points ist nicht mindestens 50“.

Sechs Regeln zum Merken

  1. if heißt „wenn“, else if heißt „sonst, wenn“, else heißt „sonst“.
  2. Jede Bedingung steht in runden Klammern. Ihr Ergebnis ist immer wahr (Ja) oder falsch (Nein).
  3. Zu jeder Bedingung gehört ein Block in geschweiften Klammern.
  4. Von allen Blöcken einer Kette läuft höchstens einer: der erste, dessen Bedingung wahr ist. Gibt es am Ende ein else, läuft sein Block, wenn keine Bedingung wahr war.
  5. Zwei Werte vergleichst du mit ==. Ein einzelnes = ist eine Zuweisung und speichert einen Wert.
  6. Mit && (und) müssen beide Bedingungen wahr sein, mit || (oder) reicht eine. ! (nicht) dreht wahr und falsch um.

Drei häufige Fehler verstehen und beheben

Wenn VS Code etwas rot unterstreicht, ist nichts kaputt. Java versteht eine Stelle im Code noch nicht und zeigt sie dir. Diese drei Fehler passieren am Anfang fast allen.

Kurz geprüft: Code im Kopf durchgehen

Hier warten fünf kurze Aufgaben zum Mitdenken. Rate nicht. Geh den Code im Kopf Zeile für Zeile durch, genau wie in den Beispielen oben. Klick erst danach auf deine Antwort.

In den Aufgaben: ein Ergebnis zurückgeben

In den Beispielen oben hat das Programm sein Ergebnis mit System.out.println ausgegeben. In den Aufgaben steht dein Code in einer Methode. Wie in Kapitel 3 gibt die Methode ihr Ergebnis mit return zurück. Das return steht dann in den Blöcken des if:

Wenn age mindestens 18 ist, gib true zurück. Sonst gib false zurück.

Mit return ist die Methode sofort zu Ende. Die Wörter public static am Anfang lässt du in den Aufgaben stehen. Was static heißt, steht in Kapitel 6.

Jetzt schreibst du selbst: drei Aufgaben im Projekt

Vom Lesen und Klicken allein lernst du das Programmieren noch nicht. Jetzt schreibst du deinen eigenen Code. Geh bei jeder Aufgabe in diesen vier Schritten vor:

  1. Lies die Aufgabe und zähl die Fälle. Wie viele verschiedene Ergebnisse gibt es?
  2. Formuliere zu jedem Fall die Bedingung: erst als Ja-Nein-Frage auf Deutsch, dann mit Vergleichszeichen.
  3. Schreib den Code: für den ersten Fall if, für weitere Fälle else if, für den letzten Fall else.
  4. Starte den Test, also das Prüfprogramm zu deiner Aufgabe. Ist ein Test rot, lies die Meldung. Sie sagt dir auf Deutsch, welcher Fall noch nicht stimmt.

Öffne das Übungsprojekt in VS Code. Die drei Aufgaben liegen im Ordner src/main/java/de/phl/crashkurs/k07. In jeder Datei wartet eine vorbereitete Methode auf dich. Zu jeder Aufgabe gibt es einen Test, der deinen Code mit Beispielen prüft.

So startest du den Test: Öffne die Testdatei und klick links neben dem Klassennamen auf den grünen Pfeil. Oder tippe den Befehl aus der Aufgabe ins Terminal (unter Windows .\gradlew.bat statt ./gradlew).
