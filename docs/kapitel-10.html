for: eine Schleife mit Zähler

Mit while aus Kapitel 9 kannst du schon zählen. Du brauchst dafür drei Dinge an drei Stellen: einen Zähler mit Startwert vor der Schleife, eine Bedingung und eine Änderung am Ende des Blocks.

Eine for-Schleife macht genau dasselbe. Sie schreibt die drei Dinge aber zusammen in eine Zeile, den Kopf der Schleife. Dort trennt je ein Semikolon die drei Teile:

forDas Wort „für“Damit fängt die Zählschleife an.
int i = 0Der StartLegt den Zähler i an. Läuft nur einmal, ganz am Anfang.
i < 3Die BedingungJava prüft sie vor jedem Durchlauf, wie bei while.
i++Der SchrittLäuft nach jedem Durchlauf des Blocks. Zählt i um 1 hoch.

Für i ab 0, solange i kleiner als 3 ist: mach den Block, und zähl danach i um 1 hoch.

Der Kopf steht in einer Zeile, aber Java führt seine drei Teile zu verschiedenen Zeiten aus. Klick dich durch und schau, welcher Teil des Kopfes gerade umrandet ist.

Die Reihenfolge ist immer dieselbe: einmal der Start. Dann im Kreis: Bedingung, Block, Schritt, Bedingung, … bis die Bedingung falsch ist.

Der Zähler i gehört nur zur Schleife. Nach der Schleife gibt es ihn nicht mehr. Deshalb verschwindet er im Speicher.

Wie oft läuft die Schleife? i < n läuft n-mal

In Java zählst du fast immer ab 0. Gleich siehst du, warum: Die Fächer eines Arrays sind ab 0 nummeriert. Für die Zahl der Durchläufe gilt diese Regel: Soll der Block n-mal laufen, startest du bei 0 und schreibst i < n. Ein Beispiel mit den 7 Tagen einer Woche:

KopfWerte von iDurchläufe
int i = 0; i < 7; i++0, 1, …, 6genau 7
int i = 0; i <= 7; i++0, 1, …, 78, einer zu viel
int i = 1; i < 7; i++1, 2, …, 66, einer zu wenig

Brauchst du Nummern ab 1, zum Beispiel für Sitzplätze, zählst du trotzdem ab 0 und rechnest i + 1.

Ein Array: eine feste Reihe von Werten

Ein Array ist eine Reihe von Werten mit fester Länge. Alle Werte haben denselben Typ und stehen unter einem gemeinsamen Namen. Die Namensliste einer Klasse sieht so aus:

Die eckigen Klammern hinter String heißen: eine Reihe von Texten. In den geschweiften Klammern stehen die Werte, getrennt durch Kommas. Eine Reihe von ganzen Zahlen wäre int[] points = {62, 49, 80};.

Stell dir das Array als Regal mit nummerierten Fächern vor. Die Nummer heißt Index und beginnt bei 0:

Eine Liste: wächst mit

Ein Array hat eine feste Länge. Bei einer Anmeldeliste für eine AG weißt du vorher nicht, wie viele kommen. Dafür gibt es die Liste: eine Reihe von Werten, die mitwächst. In Java heißt sie ArrayList.

Die Liste gehört nicht zum Grundwortschatz von Java. Deshalb holst du sie mit einer import-Zeile in deine Datei. Sie steht oben, unter der package-Zeile (falls es eine gibt) und vor public class. Schreib diese Zeilen als feste Formel ab:

In den spitzen Klammern steht, was in die Liste kommt: <String> für Texte, <Student> für Objekte der Klasse Student. new ArrayList<>() baut eine neue, leere Liste. Drei Methoden brauchst du:

club.add("Bea")hängt einen Wert hinten an die Liste an
club.get(0)holt den Wert mit der Nummer 0, also den ersten
club.size()gibt die Zahl der Werte zurück (mit runden Klammern)

Manchmal steht links List<Student> statt ArrayList<Student>, dazu oben eine zweite Zeile import java.util.List;. Du benutzt die Liste dann genauso, mit add, get und size.

Kurzform: jeden Wert einmal

Brauchst du die Nummer i nicht, gibt es eine kürzere Schleife. Sie heißt for-each („für jeden“):

Für jeden Text name in names: gib ihn aus.

Das funktioniert mit Arrays und Listen. Im nächsten Abschnitt gehst du damit eine Liste von Objekten durch. Brauchst du die Nummer i zum Rechnen, wie in Aufgabe 1, nimmst du die Schleife mit Zähler.

Eine Liste von Objekten durchgehen

Jetzt kommt alles zusammen. In einer Liste können auch Objekte liegen. Im Sitzplan ist jede Person ein Objekt der Klasse Student. Es merkt sich den Namen und die Reihe, in der die Person sitzt:

Im Beispiel kommen drei Objekte in eine Liste. Dann geht eine for-each-Schleife die Liste durch und gibt die Namen aller Personen aus, die in einer bestimmten Reihe sitzen.

Für jedes Objekt s in der Liste students: wenn es in der Reihe row sitzt, gib seinen Namen aus.

Wähl oben im Kasten eine Reihe und klick dich durch. Achte darauf, auf welche Karte die Variable s gerade zeigt.

Die Variable s zeigt in jedem Durchlauf auf ein anderes Objekt der Liste, der Reihe nach von vorn. Mit s.getRow() und s.getName() fragst du dieses Objekt nach seinen Werten, wie in Kapitel 5. Eine Nummer i brauchst du dafür nicht.

Zeile 6 baut ein Objekt und gibt es direkt an add weiter. Das geht auch in zwei Zeilen: erst Student ali = new Student("Ali", 2);, dann students.add(ali);. Beide Fassungen tun dasselbe.

Sechs Regeln zum Merken

  1. Kopf einer for-Schleife: for (int i = 0; i < n; i++). Semikolons trennen Start, Bedingung und Schritt.
  2. Der Start läuft einmal. Danach immer: Bedingung, Block, Schritt, wieder Bedingung.
  3. Ab 0 zählen. Mit i = 0 und i < n läuft der Block genau n-mal.
  4. Array: feste Länge, Fächer ab 0, names[i], Länge names.length ohne Klammern.
  5. Liste: import java.util.ArrayList; oben unter package, new ArrayList<>(), dann add, get(i) und size() mit Klammern. Steht links List<…>, brauchst du zusätzlich import java.util.List;.
  6. for-each: for (Student s : students) nimmt jedes Objekt der Liste einmal, der Reihe nach. Mit s.getName() fragst du das aktuelle Objekt nach seinen Werten.
